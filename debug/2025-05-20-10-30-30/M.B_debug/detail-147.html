B650MT는 B650 칩셋 탑재로 자동 CPU 오버클럭 기능인 PBO를 사용할 수 있으며 2개의 메모리 슬롯을 통해 DDR5 메모리를 최대 96GB까지 지원한다. 또한, 대중적으로 많이 사용하고 있는 HDMI와 DP 단자가 탑재되어 있고, DP 단자를 통해 최대 4K (4096x2160) 해상도에 60Hz의 주사율로 영상 재생도 가능하다. 게다가, SATA 3 SSD 대비 약 10배 더 빠른 PCIe4.0 M.2 SSD를 사용할 수 있으며 SMART BIOS UPDATE 기능을 지원하여 간편하게 바이오스를 업데이트할 수 있다.     BIOSTAR는 1986년 설립 이래 37년의 PC 컴포넌트에 대한 제조 경험과 노하우를 보유하고 있는 대만의 메인보드 전문 제조사로 그래픽카드, SSD, 메모리 등을 생산하고 있다. 생명력이 넘치는 영원한 별이라는 의미를 가진 BIOSTAR는 국내에서는 "생체별" 이라는 별명으로 불리며 "Beyond Better, Racing to the Future" 슬로건을 바탕으로 뛰어난 기술력으로 제품을 제작, 사업을 확장하고 있어 앞으로도 많은 기대가 되는 브랜드이다.  제이씨현시스템의 마케팅 담당자는 "BIOSTAR 브랜드는 뛰어난 품질을 자랑하는 메인보드뿐만 아니라 다양한 컴포넌트 라인업도 갖추고 있어 앞으로도 더 많은 제품을 선보일 수 있도록 노력하겠다. 라고 밝혔다.  ※ 출시 제품 라인업 (4종) 1.       안녕하세요. 테크라이프입니다.   이번에는 기존 바이오스타 B650MT 메인보드에서 전원부 개선, 메모리 슬롯 추가, PCIe 슬롯 확장, LED 헤더 추가, WiFi 안테나 슬롯 추가까지 많은 부분이 개선된 B650MT-PRO 제이씨현 메인보드를 소개하려고 합니다.   AMD 라이젠 7600 CPU와 궁합이 잘 맞는 합리적인 가격의 메인보드인데요. 과연, 어떠한 특징이 있을지 살펴보도록 하겠습니다. 구성품은 메인보드, 사용 설명서, 드라이버CD, WiFi 모듈, WiFi 모듈 설치 가이드, I/O 쉴드, SATA 케이블 2개가 동봉되어 있습니다. BIOSTAR B650MT-E PRO 제이씨현 메인보드는 기존 B650MT에서 전원부 개선, 메모리 슬롯 추가, PCIe 슬롯 확장, LED 헤더 추가, WiFi 안테나 슬롯 추가까지 많은 부분이 개선되었습니다.   검정색의 PCB 기판 레이아웃은 거의 동일하며 24.4 x 24.4cm의 제품 크기로 Micro ATX 폼팩터를 사용하고 있습니다. 성능보다는 가격이 우선되는 보급형 제품으로 전원부의 일부분만 방열판이 적용되었습니다. [PCIe 확장 슬롯] = 총 4개, PCI Express 4.0 x16 1개, 4.0 x1 3개   [SATA 포트] = 총 4개, 최대 6Gb/s 데이터 전송 속도 제공, RAID 0,1,10 어레이 지원   [M.2 슬롯] = 총 4개  M.2_1 : PCI Express 4.0 x4, 2242/2260/2280 M.2_2 : PCI Express 4.0 x4, 2280 [I/O 포트]는 왼쪽부터 DisplayPort, HDMI, BIOS 업데이트 버튼, PS/2 포트, USB 3.2 Gen2 Type-A 1개, USB 3.2 Gen2 Type-C 1개, USB 3.2 Gen1 Type-A 4개, 2.5GbE 유선랜, 오디오 포트로 구성되어 있습니다. M.2 SSD 장착부에는 나사로 고정하는 일반적인 방식에서 탈피하여 일체형 플라스틱 고정 장치로 구성되어 있어 공구 없이도 손쉽게 SSD를 장착할 수 있습니다. 주요 구성품 중 어딘가 문제가 생겼다면 LED 디버그를 통해서 문제의 원인이 일어난 위치를 파악할 수 있는 편의 기능이 탑재되어 있습니다. 기존 B650MT와 다르게 5V 헤더 2개, 12V 헤더 1개가 제공되어 사용자 입맞에 맞는 다양한 LED 시스템 용품들을 장착할 수 있습니다. 다만, CPU 쿨링팬 헤더 1개, CPU OPT 헤더 1개를 제외하고 시스템 쿨링팬을 장착할 수 있는 헤더가 단 1개만 제공되는 점은 매우 아쉬운 부분입니다. 메인보드 레이아웃에 한 가지 아쉬운 점이 있었는데요.   SATA 포트와 USB 3.2 헤더 사이에 케이스 전면 I/O 포트용 USB 3.2 Gen2 Type-C 헤더가 끼어 있는데 USB 3.2 헤더를 먼저 꽂으면 Type-C 헤더는 사진처럼 꽂을 공간이 나오지가 않습니다.   아니 이거 왜 이렇게 디자인하셨는지 도통 알 수가 없네요.. 전원부는 7+2+1 페이즈로 구성되어 있습니다.   모스펫은 Dr.mos인 Vishay SiC654 50A 제품이 사용되었습니다. Vcore 최대 출력 전류는 350A 이며, PWM 컨트롤러는 Richtek의 RT3678BE 칩셋이 사용되었습니다. BIOSTAR B650MT-E PRO 제이씨현 메인보드에서 한 가지 특이한 점은 와이파이 전용 제품이 아닌데 WiFi 안테나 액세서리와 전용 슬롯을 제공한다는 점입니다. 따라서, 무선랜카드와 와이파이 안테나만 있으면 무선으로 인터넷 사용이 가능합니다. 이더넷은 2.5GbE 기가비트 속도를 지원하는 리얼텍 RTL8125BG 칩셋이 사용되었습니다. 오디오는 리얼텍 ALC897 칩셋이 사용되었습니다. 컴퓨터 하드웨어 성능을 평가할 수 있는 대표적인 소프트웨어 시네벤치(Cinebench)로 CPU의 멀티 코어 성능과 싱글 코어 성능을 측정해봤습니다. 측정 결과, 멀티 코어는 12914점, 싱글 코어는 1540점이 측정되었습니다. CPU 코어 클럭, 전압 변동폭, 소비전력을 살펴봤습니다.   1) 3D 렌더링 도구인 블렌더(Blender)로 Classroom 데모를 렌더링 했을 때,  2) CD Project Red에서 제작한 오픈 월드 액션 게임인 Cyberpunk 2077를 구동했을 때, 3) 게임은 2560 x 1440 QHD 해상도, 울트라 퀼리티 프리셋, 레이트레이싱 활성화   * 코어 클럭  렌더링 : CPU 코어 클럭의 변화를 보면 AMD Ryzen 5 7600의 최대 코어 클럭 5.1GHz 지속 유지 게임 : CPU 코어 클럭의 변화를 보면 AMD Ryzen 5 7600의 최대 코어 클럭 5.1GHz 지속 유지 * 전압 변동폭  렌더링 : 부하가 높은 상태에서 최대 전압은 1.28v 측정 게임 : 부하가 높은 상태에서 최대 전압은 1.26v 측정 * 소비전력  렌더링 : 부하가 높은 상태에서는 108w 까지 소비 게임 : 약 77W 소비 열화상 카메라로 메인보드 전원부 주변부의 온도를 측정해봤습니다.  1) 3D 렌더링 도구인 블렌더(Blender)로 클래스룸 데모를 렌더링 했을 때, 2) CD Project Red에서 제작한 오픈 월드 액션 게임인 Cyberpunk 2077를 구동했을 때, 렌더링 : 최대 60도 측정으로 양호  게임 : 최대 58도 측정으로 양호 지금까지 BIOSTAR B650MT-E PRO 제이씨현 메인보드에 대해 살펴봤는데요.
