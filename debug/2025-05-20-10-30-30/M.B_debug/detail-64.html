AMD B850 칩셋은 최신 플랫폼인 만큼 PCIe 레인 수, 확장성, I/O 대역폭 등에서 분명 우위가 있다. 그런데도 우리가 오늘 이야기하려는 건 B650 메인보드다. 그 이유는 명확하다. 현 시점에서 '가격 대비 성능'이라는 키워드를 가장 설득력 있게 설명해주는 칩셋이 바로 B650이기 때문이다. 다름 아닌 10만 원대 메인보드로 말이다. 이제 막 PC를 새로 맞추려는 유저, 혹은 업그레이드를 고려 중인 실속파 소비자에게는 PCIe 5.0 지원, DDR5 메모리 호환, 빠른 속도의 유선랜 정도만 제대로 제공돼도 부족함이 없다. 실제로 B650 보드는 출시된 지 시간이 꽤 지나면서 바이오스 안정화, 메모리 호환성 확보, 다양한 모델군 선택지 확보까지 모두 완성된 상태다. 성숙기에 접어든 기술이 안정성과 합리적인 가격을 동시에 제공하는 건 어쩌면 당연한 일이다. 즉, 지금 B650을 고르는 건 시대에 뒤처진 선택이 아니라, 시대를 읽은 선택이다. 소개하는 애즈락의 10만 원대 메인보드가 바로 그 증거다. 대상으로 선정된 메인보드는 다음과 같다. 기준은 10만 원대 B650 제품군 중 가격비교사이트에서 판매량이 높은 제품이다. - ASRock B650M Pro RS - ASRock B650M PG Lightning - ASRock B650M Pro X3D - ASRock B650M-HDV/M.2 1-1. ASRock B650M Pro RS 매력적인 사양과 완벽한 균형을 갖춘 현대적이고 미래지향적인 레이스 스포츠(RS) 에디션으로, 인기 높은 프로 시리즈 메인보드의 진화다. 값비싼 업그레이드 없이도 뛰어난 성능과 신뢰할 수 있는 컴퓨팅 경험을 제공한다. 모든 작업과 가벼운 로딩 게임까지 스타일과 속도로 처리하는 만능 마더보드다. 1-2. ASRock B650M PG Lightning PCIe 5.0, 여러 개의 M.2 슬롯, Dragon 2.5G 이더넷, 편리한 통합 IO 실드를 포함한 제품이다. 14+2+1 SPS 전원 단계와 프리미엄 8층 PCB 디자인으로 저렴한 가격에 고품질의 기능을 제공한다. 강력하면서도 경제적인 엔트리급 게이밍 시스템을 구축하기에 최적이다. 1-3. ASRock B650M Pro X3D AMD Ryzen X3D 프로세서에 최적화되어 뛰어난 안정성, 호환성 및 향상된 성능을 제공해 게임과 창작에 이상적이다. 1-4. ASRock B650M-HDV/M.2 합리적인 가격으로 DDR5 메모리를 지원하며, 다양한 연결 옵션으로 뛰어난 확장성과 안정적인 시스템 운영을 제공한다. 2. 전원부와 메모리를 확인해야 한다 CPU를 안정적으로 구동하려면 결국 전원부가 중요하다. AM5 CPU 특성상 전력 소모가 큰 편이어서, 여기에 잘 대응할 수 있어야 한다. 제품명 폼팩터 전원부 구성 페이즈당 전류 Vcore 단일 출력 ASRock B650M Pro RS M-ATX 8+2+1 페이즈 50A O ASRock B650M PG Lightning M-ATX 6+2+1 페이즈 50A O ASRock B650M Pro X3D M-ATX 8+2+1 페이즈 - - ASRock B650M-HDV/M.2 M-ATX 8+2+1 페이즈 50A O 전원부 구성만 놓고 보면 3강 1약이다. B650M Pro RS, B650M Pro X3D, B650M-HDV/M.2가 8+2+1 페이즈로 동일하다. B650M PG Lightning은 6+2+1 페이즈로 한 단계 낮다. VCore 출력 합계를 계산하면 B650M Pro RS와 B650M-HDV/M.2는 페이즈당 50A로 총 400A까지 지원한다. 이 정도면 고성능 CPU도 무난하게 사용할 수 있다. ASRock B650M Pro X3D는 페이즈당 전류 정보가 공개되지 않았지만, 제품의 네이밍만으로도 ASRock B650M Pro RS나 ASRock B650M-HDV/M.2보다 떨어질 이유가 전혀 없다. 기본 정보부터가 라이젠 X3D 프로세서에 최적화된 메인보드이기에 그렇다. 반면, B650M PG Lightning은 6+2+1 페이즈 구성으로 페이즈당 50A에 총 VCore 출력 합계가 300A로 다소 약한 편이다. 라이젠 7 이상의 프로세서를 사용할 경우에는 부담이 될 수 있다. 요약하면, 전원부만 놓고 볼 때 고사양 CPU를 사용할 예정이라면 B650M Pro X3D가 가장 적합하다. 메인스트림 CPU에는 B650M Pro RS와 B650M-HDV/M.2가 좋으며, 보급형 CPU라면 B650M PG Lightning이 알맞다. 메모리에 관해서도 조금 더 이야기해 보자. 10만 원대 메인보드라 메모리 성능은 큰 차이가 없다고 생각할 수 있지만, 자세히 보면 조금의 차이는 있다. 메모리 속도는 8000MHz(PC5-64000)를 지원하는 ASRock B650M Pro X3D 에즈윈이 가장 뛰어나다. 그 외 제품은 속도가 비슷비슷한 수준인데, 메모리 슬롯 개수가 다른 메인보드보다 적은 제품이 있다. 바로 B650M-HDV/M.2로, 메모리 슬롯이 2개뿐이다. 그런 점만 놓고 본다면, 메모리 슬롯이 4개인 B650M PG Lightning이 B650M-HDV/M.2보다는 조금 더 낫다고 할 수 있다. 3. M.2 슬롯 개수와 PCIe 지원 여부 최근 개인 소비자용 저장장치 시장에서는 HDD는 물론이고 SATA SSD조차 보기 힘들어졌다. 이제 대세는 NVMe SSD다. 따라서 스토리지 성능에 신경을 쓴다면 M.2 슬롯 개수와 PCIe 5.0 지원 여부를 반드시 확인해야 한다. 내친김에 VGA 연결 시 PCIe 규격도 함께 확인하면 더욱 좋다. 제품명 VGA 연결 M.2 SATA3 M.2 연결 방식 M.2 폼팩터 ASRock B650M Pro RS PCIe4.0 x16 3개 4개 PCIe5.0 / PCIe4.0 / NVMe 2260 / 2280 ASRock B650M PG Lightning PCIe4.0 x16 3개 4개 PCIe5.0 / PCIe4.0 / NVMe 2260 / 2280 ASRock B650M Pro X3D PCIe5.0 x16 3개 4개 PCIe5.0 / PCIe4.0 / NVMe 2280 ASRock B650M-HDV/M.2 PCIe4.0 x16 2개 4개 PCIe5.0 / PCIe4.0 / NVMe 2260 / 2280 눈여겨볼 포인트는 다음과 같다. 우선 M.2 슬롯을 3개 제공하는 모델은 Pro RS, PG Lightning, Pro X3D다. 여유롭게 고속 SSD를 여러 개 구성할 수 있다. 특히 Pro X3D는 유일하게 VGA 슬롯이 PCIe 5.0 x16이라서 고성능 CPU와 함께 차세대 그래픽카드를 사용할 계획이라면 충분한 이점이 있다. B650M-HDV/M.2는 전원부는 튼튼하지만 M.2 슬롯이 2개로 제한적이다. 즉 저장장치 확장이 많이 필요 없는 간단한 시스템에 더 잘 어울린다. 또 다른 특이점으로는 모든 모델이 최소 1개의 PCIe 5.0 M.2 슬롯을 지원한다는 점이다. 즉, 마음만 먹으면 최신 NVMe SSD를 최대 성능으로 활용할 수 있다는 것이다. 정리하자면 M.2 슬롯이 3개 이상이고 PCIe 5.0 지원이 필요하다면 PG Lightning 또는 Pro RS가 가장 무난한 선택지다. 여기에 차세대 그래픽카드를 포함한 고사양 시스템을 고려한다면 Pro X3D가 가장 좋다. 반면 간단한 PC 구성이라면 B650M-HDV/M.2 역시 충분히 합리적이며, 앞서 언급했듯 전원부가 튼튼한 것도 큰 장점이다. 4. 일상 사용의 편리함, 확장슬롯과 USB 포트 구성 포트 구성은 실사용에서 체감 차이가 크게 나타난다. 모델명 그래픽 출력 USB A USB C USB 타입 기타 후면단자 ASRock B650M Pro RS HDMI, DP 7개 1개 Type-C (10Gbps) Type-A (10Gbps) USB3.x 10Gbps USB3.x 5Gbps USB 2.0 RJ-45 오디오잭 BIOS플래시백 ASRock B650M PG Lightning HDMI, DP 7개 1개 Type-C (10Gbps) Type-A (10Gbps) USB3.x 10Gbps USB3.x 5Gbps USB 2.0 RJ-45 오디오잭 BIOS플래시백 ASRock B650M Pro X3D HDMI, DP 7개 1개 Type-C (10Gbps) Type-A (10Gbps) USB3.x 10Gbps USB3.x 5Gbps USB 2.0 RJ-45 오디오잭 BIOS플래시백 ASRock B650M-HDV/M.2 HDMI, DP 6개 1개 Type-C (5Gbps) USB3.x 5Gbps USB 2.0 RJ-45 오디오잭 USB 포트를 기준으로 평가하면 조금 다르게 3강 1약이다. ASRock B650M Pro RS, B650M PG Lightning, B650M Pro X3D가 3강이고, ASRock B650M-HDV/M.2가 1약이다. 앞서 전원부 평가 때와는 반대되는 양상이다. 일단 본문에서 언급한 애즈락 메인보드 모두 USB Type-C 포트를 제공한다. 여기에 B650M Pro RS, B650M PG Lightning, B650M Pro X3D는 바이오스 플래시백 버튼도 갖추고 있다. USB Type-A 포트가 7개라면 부족한 편은 아니다. 또한 Type-C와 Type-A 모두에서 최대 10Gbps의 속도를 제공하므로 충분히 쓸 만하다. 반면 속도가 크게 중요하지 않다면 ASRock B650M-HDV/M.2와 다른 메인보드의 차이는 그리 크지 않다. 단지 USB Type-A 포트가 하나 적을 뿐이기 때문이다. 요약하자면, USB 연결 기기가 많다면 B650M Pro RS, B650M PG Lightning, B650M Pro X3D가 적합하며, 비교적 가벼운 용도로 사용할 계획이라면 B650M-HDV/M.2도 무난한 선택이다. 5. 즐거운 게임 시스템을 만드는 오디오와 네트워크 오디오와 네트워크는 사실 고가의 메인보드에서야 비로소 명확한 차이가 드러나는 요소다. 메인스트림급 메인보드는 대부분 비슷한 수준이며, 이미 상향 평준화되어 있어 뚜렷한 차이로 등급을 나누기 어려운 분야이기도 하다. 본문에서 열거한 메인보드가 좋은 예다. 오디오는 전 제품이 공통적으로 Realtek ALC897 칩셋을 채택했으며, 이는 일상적인 사용에는 충분한 수준이다. 유선랜은 대부분 2.5Gbps 급인 RTL8125BG를 탑재했다. 실제로 이 정도 속도라면 일상생활에서는 절대 부족함이 없다. 요약하면, 오디오와 네트워크는 10만 원대 AM5 메인보드 간에는 거의 차이가 없다고 봐도 무방하다. ** 편집자 주 메인보드 성능을 간략하게 알아봤다. 이제 가격만 알아보면 끝이다. 가격은 다음과 같다(2025년 3월 29일 다나와 최저가 기준) 모델명 가격 ASRock B650M Pro RS 193,000 ASRock B650M PG Lightning 155,940 ASRock B650M Pro X3D 203,990 ASRock B650M-HDV/M.2 165,790 가격만 놓고 차례대로 정리하면, B650M Pro X3D, B650M Pro RS, B650M-HDV/M.2, B650M PG Lightning 순이다. B650M Pro X3D는 20만 원을 넘어서며 10만 원대 범주에서 조금 벗어난 수준이다. B650M Pro RS는 10만 원대 후반으로 20만 원대에 가깝고, 실제로 10만 원 중반대라 부를 만한 모델은 B650M-HDV/M.2와 B650M PG Lightning이다. B650M-HDV/M.2와 B650M PG Lightning은 중점을 어디에 두느냐에 따라 선택지가 달라지는 메인보드다. 전원부 성능을 중요하게 생각한다면 B650M-HDV/M.2를, 전원부 외에 메모리 슬롯 수나 시스템 편의성을 고려한다면 B650M PG Lightning을 선택하면 된다. 사실 가성비를 기준으로 무엇이 더 낫다고 명확히 고르기 어려울 만큼 모두 훌륭한 메인보드다. 그러나 꼭 하나를 골라야 한다면 B650M PG Lightning이 상당히 매력적으로 보인다. 라이젠 5 프로세서와 함께 사용할 경우, 구성 자체가 균형 잡혀 있고 특별히 불편한 점도 없기 때문이다. 간단하게 결론을 정리하면 다음과 같다. - 확장성이 뛰어난 가성비 게이밍 메인보드: B650M PG Lightning - 내구성이 좋은 사무용/인강용 PC 메인보드: A620M-HDV/M.2 - 못 하는 게 없는 만능 메인보드: Pro RS - 고성능 CPU와 잘 어울리는 메인보드: Pro X3D 소개한 제품이라면 라이젠 기반 PC 구성의 좋은 출발점이 될 것이다. 단지 가격만 싸다고 하면 결국 ‘비지떡’일 뿐이다. 진짜 가성비는 가격과 더불어 성능과 구성, 확장성까지 두루 갖춘 제품을 의미한다. 그런 면에서 애즈락 메인보드와 함께라면 실패할 일은 없어 보인다.
